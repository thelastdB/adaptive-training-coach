
# Eigentakt — Brand System

## Brand Summary

Eigentakt is a private adaptive training system for serious recreational endurance athletes.

The brand is positioned against:
- performative fitness culture
- optimization maximalism
- loud coaching aesthetics
- gamified motivation systems

The emotional territory is:
- rhythm
- pacing
- calibration
- consistency
- sustainable progression
- quiet discipline

The product should feel like a precision instrument for endurance practice.

## Motion Direction
Motion should feel:
- pendular
- measured
- rhythmic
- controlled

Avoid:
- bounce
- flashy transitions
- gamified movement

## Photography Direction
Photography should emphasize:
- ritual
- preparation
- calm effort
- endurance
- quiet focus
- golden hour light
- muted tones

Avoid:
- victory poses
- fitness clichés
- performative intensity

## UI Direction
The interface should feel:
- spacious
- editorial
- instrument-like
- information-dense but calm

Avoid:
- dashboard overload
- bright performance colors
- startup SaaS aesthetics

## Writing Style
Copy should feel:
- calm
- exact
- understated
- observant

Avoid:
- hype
- motivational clichés
- startup jargon

## Core Brand Principle
Eigentakt should always feel quieter than expected.
